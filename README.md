# Algo Zenith

A 90-day journey of solving Data Structures and Algorithms problems from scratch using Java.

## 🎯 Goal

Solve 3–4 problems every day for 90 consecutive days, focusing on:

- Problem-solving
- DSA fundamentals
- Pattern recognition
- Algorithmic thinking
- Clean Java implementation
- Time and space complexity

## 🧑‍💻 Language

- Java

## 🧩 Platform

- LeetCode

## 📚 Learning Approach

Every problem is documented with:

1. Problem statement
2. Approach / intuition
3. Brute-force solution, when applicable
4. Optimized approach
5. Step-by-step explanation
6. Example / dry run
7. Time complexity
8. Space complexity
9. Key takeaway
10. Clean Java implementation

## 🗺️ Roadmap

| Phase | Days | Topics |
|---|---:|---|
| 1 | 1–15 | Arrays, Strings, Basic Hashing |
| 2 | 16–30 | Hashing, Two Pointers, Sliding Window |
| 3 | 31–45 | Linked List, Stack, Queue |
| 4 | 46–60 | Binary Search, Trees, Heap |
| 5 | 61–75 | Recursion, Backtracking, Graphs |
| 6 | 76–90 | Greedy, Dynamic Programming, Revision |
